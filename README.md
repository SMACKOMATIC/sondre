# sondre.com

Privat hjemmeside hostet på Pair.com.

## Struktur

Nettstedet består av enkle HTML-filer med innebygd CSS og JavaScript.

## Hosting

- **Live server:** Pair.com (sondre.com)
- **GitHub backup:** github.com/sondre

## Vedlikehold

1. Rediger filer lokalt på Windows-PC
2. Last opp til GitHub for versjonkontroll
3. Publiser på Pair.com via WinSCP

## Opplasting til Pair

Bruk WinSCP:
- Koble til Pair FTP
- Naviger til `/usr/www/users/sondre1/public_html/`
- Dra filene fra PC og slipp dem på serveren
